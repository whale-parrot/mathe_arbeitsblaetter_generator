## 🎉 First Stable Release!
Welcome to the first official release of the **Zahlen Wettrennen Generator**. This tool allows teachers and parents to easily create custom, randomized math worksheets for number recognition and counting.

### ✨ Features in v1.0.0
- **Custom Number Ranges:** Generate worksheets for any number range (e.g., 1-10 for beginners, 1-100 for advanced).
- **Icon Replacement:** Seamlessly blend digits with visual icons to help kids associate numbers with quantities.
- **Multiple Icon Sets:** Supports various visual styles (Dice, Hands, etc.) with customizable distribution weights.
- **Smart Hand Rendering:** Automatically composites left/right hands for numbers greater than 5.
- **Live PDF Preview:** Instantly preview the generated worksheet directly in the browser before downloading.
- **Standalone Desktop App:** Packaged as a single executable file. No Python installation required!

### 📥 Installation & Usage
1. Download the `math-worksheets` executable file from the **Assets** section below.
2. Double-click the file to run it. 
3. Your default web browser will automatically open to `http://localhost:8501` with the app interface.
4. Configure your settings in the sidebar, click **Generate Worksheet**, and download your PDF!

### 🐛 Known Issues
- First launch may take a few seconds as the app unpacks its temporary files.
